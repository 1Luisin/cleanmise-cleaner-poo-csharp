# 🧹 CleanMise

Aplicação para exclusão automática de arquivos temporários do Windows, desenvolvida com C# e POO.

## Funcionalidades
- Identifica arquivos temporários
- Exclui arquivos obsoletos automaticamente
- Interface simples e direta

## Tecnologias
- C#
- Programação Orientada a Objetos

## Objetivo
Automatizar a limpeza de arquivos inúteis do sistema com boas práticas de desenvolvimento.
